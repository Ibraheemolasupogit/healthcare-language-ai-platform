# Portfolio Evidence

Milestone 12 evidence starts with `reports/portfolio/evidence-index.json`,
`reports/portfolio/run-registry.json`, `reports/release/release-readiness.json`
and `reports/release/release-manifest.json`. The final reviewer package is
created under `outputs/portfolio-release/<release-id>` for local inspection.

The portfolio summary is generated from local manifests and approval evidence, not hard-coded metrics.

It describes completed milestones, capabilities, approved retrieval baseline, approved RAG prototype, deterministic fixtures, quality results, safety controls, architecture boundaries, target roles, interview talking points, and known limitations.
