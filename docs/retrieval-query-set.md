# Retrieval Query Set

The checked-in query benchmark includes direct, paraphrased, compositional,
distractor, negation-sensitive, metadata-filtered, numeric-detail, and
unanswerable queries. Relevance judgments are manually authored from deterministic
synthetic lineage.

Each query records category, difficulty, target unit type, metadata filters,
generation method, and leakage risk.
## Expanded Benchmark

The Milestone 7 benchmark expands to 95 queries across direct, paraphrased, compositional, distractor, negation-sensitive, numeric-detail, metadata-filtered, cross-granularity, abbreviation, section-alias, multi-relevant, and unanswerable groups. Each query records authoring method, leakage risk, source-overlap ratio, split, and holdout status.
