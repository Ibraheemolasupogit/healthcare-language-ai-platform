# Vector Search Target State

The Databricks Vector Search design is a dry-run target-state contract. It defines
an endpoint placeholder, index placeholder, primary key, embedding column, metadata
filter columns, access-control expectations, sync strategy, and versioning notes.

No endpoint is created or contacted.
## Retrieval Quality Target State

Milestone 7 comparison evidence includes a Databricks retrieval plan placeholder for future vector-search alignment. The plan is dry-run only and records that no connection or execution is permitted.
