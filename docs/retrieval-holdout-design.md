# Retrieval Holdout Design

The retrieval holdout is a locally authored synthetic corpus independent from the original generation templates. It includes 40 documents across clinical notes, discharge summaries, referral letters, radiology reports, and pathology reports.

The holdout varies section headings, document length, sentence structure, abbreviations, negation, numeric expressions, distractors, and section order. It uses synthetic identifiers only and runs privacy and clinical-safety checks.

Vocabulary overlap is measured and disclosed rather than treated as absent.
