# Milestone 5

Milestone 5 adds deterministic clinical entity extraction, document classification,
baseline evaluation, error analysis, model-card evidence, and MLflow dry-run
contracts.

Scope is limited to controlled synthetic fixtures and transparent local rules. It
does not train models, download models, use clinical terminology systems, connect to
MLflow, connect to Databricks, or implement later milestones.

Definition of done is reproducible extraction and evaluation fixtures, validated
metrics, passing reconciliation, and documentation of benchmark leakage.
