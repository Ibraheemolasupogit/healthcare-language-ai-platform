# Milestone 6

Milestone 6 adds local retrieval corpus construction, keyword retrieval, TF-IDF,
BM25, deterministic hash-vector embeddings, hybrid retrieval, metadata filtering,
query benchmark fixtures, retrieval evaluation, failure analysis, index/model
cards, MLflow dry-run retrieval planning, and Databricks Vector Search target-state
planning.

It does not implement RAG, hosted embeddings, LLM answers, live vector databases,
cloud resources, or later milestones.
